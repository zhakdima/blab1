# 6 вариант первой лабораторной работы

## 1. Описание проекта

Класс Фабрика хранит данные о мебели, работниках и машинах.Для мебели определено: тип мебели, габариты (высота, ширина, глубина), цвет, материал, стоимость. Для работника определено: ФИО, должность, заработная плата, адрес проживания, телефон. Для машины определено: марка, модель, гос.номер

## 2. Структура проекта

- **FactoryItem.h / FactoryItem.cpp** - базовый абстрактный класс, общие методы работы с объектами, функции ввода и проверки данных.
- **Furniture.h / Furniture.cpp** - класс мебели.
- **Worker.h / Worker.cpp** - класс работника.
- **Car.h / Car.cpp** - класс машины.
- **Factory.h / Factory.cpp** - контейнер для хранения и управления объектами фабрики.
- **main.cpp** - главное меню и взаимодействие с пользователем.

## 3. Характеристики объектов

**Мебель:** тип, высота, ширина, глубина, цвет, материал и стоимость.

**Работник:** ФИО, должность, заработная плата, адрес проживания и телефон.

**Машина:** марка, модель и государственный номер.

## 4. Возможности программы

- Добавление объектов всех трёх типов.
- Просмотр всех записей и записей выбранной категории.
- Изменение данных объектов.
- Удаление записей.
- Задание названия фабрики.
- Сохранение данных фабрики в файл.
- Восстановление данных из файла.
- Обработка исключительных ситуаций с выводом поясняющих сообщений.

При сохранении записывается название фабрики, количество объектов, тип каждого объекта и его характеристики. При загрузке программа восстанавливает объекты соответствующих классов.

## 5. Особенности реализации

- Использование объектно-ориентированного программирования и наследования.
- Применение абстрактного базового класса и виртуальных методов.
- Динамическое выделение и освобождение памяти.
- Хранение записей в динамическом массиве указателей без использования STL-контейнеров.
- Реализация конструкторов, конструктора копирования и деструкторов.
- Перегрузка операторов.
- Использование методов получения и установки значений полей.
- Проверка корректности вводимых данных и обработка исключений.
- Разделение объявлений классов и реализаций на файлы `.h` и `.cpp`.

## 6. Сборка и запуск

1. Открыть файл `blab1.slnx` в Visual Studio.
2. Собрать решение.
3. Запустить программу.
4. Выбрать необходимое действие в главном меню.

Для сохранения и загрузки данных пользователь указывает имя или путь к файлу.
